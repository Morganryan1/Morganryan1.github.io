Automated PNG-to-Polygon Conversion

ArcGIS ModelBuilder · Spatial Automation

Developed during my internship with the Nebraska Department of Transportation (ROW Division), this ArcGIS ModelBuilder workflow converts scanned right-of-way project images into clean, usable GIS data. The model automates reclassification, polygon extraction, and topological cleanup — turning hours of manual digitizing into a consistent, repeatable process.

COVID-19 Food Bank Map

Open Source · Javascript · Data Scraping

This custom web map, “Lincoln Food Distribution Centers,” is a lightweight interactive mapping application uilt during the COVID-19 pandemic to help visualize and locate food distribution centers in Lincoln, Nebraska. It’s a Leaflet.js-based web map that integrates data from OpenStreetMap and the Lincoln Food Bank’s “Food Finder” website, allowing users to easily find food access points across the city.

2021 AAG GPRM Meeting Map

Open Source · Javascript · Data Scraping

This interactive web map, “AAG GPRM Meeting 2021,” was developed for attendees of the Great Plains–Rocky Mountain Regional AAG Conference in Lincoln, Nebraska. Built with Leaflet.js, Bootstrap, and Font Awesome, it highlights local restaurants, bars, historic landmarks, and the Graduate Lincoln hotel, providing an engaging and mobile-friendly guide to the conference area through interactive popups and custom map icons.

2021 AAG GPRM Workshop

Open Source · Javascript · OSM Overpass

This interactive Leaflet web map was created for a live mapping workshop during the 2021 Great Plains–Rocky Mountain AAG Meeting. It demonstrated core web GIS concepts such as GeoJSON integration, feature styling, marker clustering, and dynamic legends, allowing participants to explore mock data and experiment with spatial interactivity in real time.
